功能特性

在 PCL Community Edition 基础上二次开发，专注纯净体验与易用性。

微软正版登录

使用 OAuth 设备码流，无需填写任何应用密钥即可完成正版验证，登录更安全、更省心。

第三方皮肤站

多语言

常见问题

正版登录为什么不需要填写应用密钥？

微软正版登录采用 OAuth 设备码流（RFC 8628）。该流程属于公开客户端（public client），只需一个公开的 client_id，无需也不应使用客户端密钥，因此你只需要在弹出的浏览器里授权即可，启动器本身不保存任何密钥。

我该下载 x64 还是 ARM64？

绝大多数 Intel / AMD 台式机、笔记本选择 x64；搭载骁龙、三星等 ARM 芯片的 Windows 平板 / 便携本选择 ARM64。不确定时选 x64，也可以直接使用上方的友好模式让它自动匹配。

如何反馈问题或提交建议？

请前往 GitHub Issues 提交，附上启动器日志与复现步骤会更快得到处理。

PCL-In 与 PCL2 是什么关系？

PCL-In 是基于 PCL Community Edition (PCL-CE) 的二次 fork，并进一步独立开发与维护。
